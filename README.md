# Live Korean Captions

영어와 한국어 사이의 실시간 자막을 제공하는 macOS 앱입니다. 마이크로 한 사람의 말을 듣거나 이 Mac에서 재생되는 소리를 받아, 선택한 방향으로 번역해 화면에 표시합니다. 언어 모델을 준비한 뒤에는 음성 인식과 번역을 Mac 안에서 처리합니다.

![Live Korean Captions 미리보기](docs/images/caption-preview.png)

*예시 대화를 표시한 미리보기 화면입니다.*

## 주요 기능

- **양방향 자막**: 시작 전에 영어 → 한국어 또는 한국어 → 영어를 선택하고, 대화 도중에도 방향을 바꿀 수 있습니다.
- **떠 있는 자막 창**: 다른 앱 위에 간략 보기를 띄우고 위치와 크기를 조절합니다.
- **원문 함께 보기**: 상세 보기에서 원문과 번역을 함께 읽고 글자 크기를 바꿉니다.
- **기록 저장**: 대화의 전체 원문과 번역을 텍스트 파일로 내보냅니다.
- **로컬 처리**: 번역용 서버나 API 키 없이 Apple의 기기 내 음성 인식과 번역을 사용합니다.
- **선택적 번역 보완**: 작은 로컬 모델로 확정된 문장을 다시 번역합니다. 기본값은 꺼져 있습니다.
- **여러 용어사전**: AI·IBM·금융권을 함께 선택해 분야와 공개 용어를 참고하고, 개인 사전을 여러 개 추가합니다. 개인 용어와 오인식 표기는 이 Mac에만 저장합니다.

## 빌드 및 실행

Apple Silicon Mac과 macOS 26.4 이상이 필요합니다. 빌드에는 macOS 26.4 이상을 지원하는 SDK, Swift 6 이상의 도구, Python 3가 필요합니다. Xcode 또는 Command Line Tools를 설치한 뒤 실행하세요.

```sh
git clone https://github.com/SeoJHeasdw/live-ko-catption.git
cd live-ko-catption
./scripts/build-app.sh
open "dist/Live Korean Captions.app"
```

첫 빌드에서는 로컬 번역 런타임의 소스와 빌드 도구를 다운로드합니다. 생성되는 앱은 로컬 실행용 임시 서명을 사용합니다. Developer ID 서명과 공증을 거친 배포용 앱은 아닙니다. 자세한 구성은 [개발 가이드](docs/development.md)를 참고하세요.

## 처음 사용하기

1. 빈 대화에서 상단의 **번역 방향**을 선택합니다.
2. 화면 중앙의 **언어 모델 준비**를 눌러 선택한 언어의 음성 인식·번역 모델을 내려받습니다. 처음 준비할 때 인터넷이 필요하며, macOS에서 다운로드 허용을 요청할 수 있습니다.
3. 기본값인 **마이크 · 자동 선택 (시스템 기본)**으로 시작 시 시스템 기본 마이크를 사용합니다. 다른 마이크를 쓰거나 영상·회의처럼 이 Mac에서 재생되는 소리를 자막으로 만들려면 왼쪽 사이드바의 **설정 → 입력**에서 선택하세요. **컴퓨터에서 나는 소리**를 고르면 처음 시작할 때 macOS가 시스템 오디오 녹음 허용을 묻습니다. 장치 목록은 설정을 열거나 자막을 시작할 때 갱신됩니다.
4. 하단의 **자막 시작**을 누르고 macOS의 마이크 접근을 허용합니다. 시작이 완료되면 간략 보기로 전환합니다.
5. 선택한 입력 언어로 말합니다. **일시정지**로 대화를 유지한 채 입력을 멈추고, **자막 재개**로 이어갈 수 있습니다.
6. 대화가 끝나면 왼쪽 사이드바의 **기록 저장**을 눌러 전체 원문과 번역을 보관합니다.

기록은 자동 저장되지 않습니다. 앱을 종료하거나 **새 대화**를 시작하기 전에 필요한 기록을 저장하세요. 기록이 있는 대화의 용어사전 선택을 바꾸려면 새 대화를 시작해야 합니다.

**대화 중 방향 전환**: 질문이 다른 언어로 나오는 자리에서는 간략 창의 ⇄ 버튼, 상세 창 상단의 번역 방향 버튼 또는 `⌘D`로 방향을 반대로 바꿉니다. 듣는 중이면 마지막 문장을 정리한 뒤 다른 언어로 다시 듣기 시작하며, 그 사이의 말은 놓칠 수 있습니다. 이전 자막은 그대로 남고 저장 기록의 각 구절은 자기 언어 표시를 유지합니다. 두 방향의 언어 모델이 모두 준비돼 있어야 합니다.

## 보기와 조작

**간략 보기**는 최근 문장별 자막을 보여주는 반투명 창입니다. 위쪽을 드래그해 이동하고, 테두리나 모서리를 잡아 크기를 조절합니다. 창 높이를 늘리면 더 많은 줄을 볼 수 있으며, 긴 자막은 최신 끝부분을 표시합니다. 다음 구절의 번역을 기다리는 동안에는 읽을 수 있는 이전 자막을 유지합니다. 창에 마우스를 올리면 상세 보기, 일시정지·재개, 일시정지하고 상세 보기 버튼이 나타납니다. **설정 → 자막**의 **발표·전체 화면 위에도 간략 창 표시**가 켜져 있으면(기본값) 슬라이드쇼나 전체 화면 영상 위에도 맨 위에 표시합니다. 메뉴나 시스템 알림을 가리면 창을 옮기거나 이 설정을 끄세요.

**상세 보기**는 자막을 넓게 표시합니다. 상단에서 번역 방향을 선택하고 왼쪽 사이드바를 접거나 펼칩니다. 사이드바에는 간략 보기·전체 화면·기록 저장·새 대화·설정이 있으며, 접힌 상태에서도 아이콘으로 사용할 수 있습니다. 아이콘에 마우스를 올리면 설명이 나타나고, 사이드바의 접힘 상태는 다음 실행에도 유지됩니다.

사이드바의 톱니바퀴 **설정**을 열면 **자막·번역·입력** 탭에서 원문 표시, 글자 크기, 번역 옵션과 입력 장치를 바꿀 수 있습니다. 자막 시작·일시정지·재개 버튼은 화면 하단에 있습니다.

화면에는 최근 100개 표시 구절을 보여주며, 저장 파일에는 전체 기록이 포함됩니다. 자막을 직접 스크롤하면 자동 따라가기가 멈춥니다. **최신 자막으로**를 눌러 다시 켤 수 있습니다.

보기 전환과 일시정지는 현재 대화의 기록을 유지합니다. **일시정지하고 상세 보기**는 입력을 멈추고 상세 창으로 돌아옵니다.

| 단축키 | 동작 |
|---|---|
| `Space` | 자막 시작·일시정지·재개 |
| `⌘1` | 상세 보기 |
| `⌘2` | 간략 보기 |
| `⌘\` | 사이드바 접기·펼치기 |
| `⌘.` | 일시정지하고 상세 보기 |
| `⌘D` | 번역 방향 전환 |
| `⌘S` | 전체 원문·번역 기록 저장 |

단축키는 앱이 활성화된 상태에서 사용합니다.

## 자막 상태와 번역 설정

회색 자막은 인식이나 번역이 진행 중이며 내용이 바뀔 수 있습니다. 음성 인식이 확정되고 현재 원문에 대한 번역을 받으면 밝은 자막으로 표시합니다. **밝은 자막은 번역의 의미가 검증됐다는 뜻이 아닙니다.**

**설정 → 자막**에서 **원문 함께 보기**와 **자막 글자 크기**를 조절합니다. 원문 표시는 선택한 번역 방향의 입력 언어를 따릅니다.

**설정 → 번역**에서 **최근 구절 함께 번역**을 켜면 발화가 잠시 잦아든 뒤 인접한 구절을 묶어 다시 번역합니다. 묶음 번역은 상세 보기와 저장 기록에 표시하며, 최근 자막이 회색으로 돌아갔다가 수정될 수 있습니다. 간략 보기는 읽던 내용이 통째로 바뀌지 않도록 문장별 번역을 유지합니다. 오래된 대화 전체를 반복해서 번역하지는 않습니다.

**설정 → 번역 → 용어사전 적용**에서 **AI·IBM·금융권**을 여러 개 선택합니다. 선택하지 않으면 일반 번역을 사용합니다. 사이드바에는 선택한 사전이 표시됩니다. 빈 대화에서 시작 전에 고를 수 있고, 선택은 다음 실행에도 유지됩니다. 분야 설명과 해당 문장에 등장한 용어는 작은 로컬 모델의 확정 문장 다듬기에 참고로 전달하며, Apple의 빠른 번역에 용어쌍을 직접 전달하지는 않습니다. 기본 사전은 공개 공식 자료를 확인한 AI 용어 20개·IBM 제품명 20개·금융권 용어 22개이며 [조사 기록](docs/research/ai-glossary-20261002.md)에 출처와 적용 범위를 남겼습니다. 전문 용어가 일관되게 쓰이도록 돕지만 의미 정확성이나 자연스러운 의역을 보장하지 않습니다.

**작은 로컬 모델 사용**은 문장 다듬기를 위한 시험 기능입니다. 약 1.47 GB의 Hy-MT2-1.8B Q6_K 모델을 내려받은 뒤 켤 수 있습니다. 빠른 Apple 번역을 먼저 표시하고 확정된 원문만 보완합니다. 보완이 늦거나 실패하면 빠른 번역을 유지합니다. 어색한 결과가 나오면 보완을 끄세요.

**용어사전 추가…**를 눌러 이름을 정하면 개인 사전 파일을 만들고 편집기로 엽니다. 한 줄에 용어 하나씩 `영어 = 한국어 | 잘못 들리는 표기, 잘못 들리는 표기` 형식으로 적습니다. `= 한국어`를 빼면 이름을 번역하지 않고 그대로 두며, `| ...`는 생략할 수 있습니다. 파일 위쪽의 `# 문맥:` 뒤에는 그 사전이 필요한 분야를 짧게 설명할 수 있습니다. 저장한 뒤 **다시 읽기**를 누르고 해당 사전을 선택하세요. 개인 사전은 기본 사전과 함께 선택할 수 있고, 개인 지정 번역이 같은 기본 용어보다 우선합니다. 같은 우선순위의 사전이 다른 번역을 지정하면 해당 용어를 참고에서 제외하고 충돌을 표시합니다.

선택한 개인 사전에 직접 적은 잘못 들리는 표기만 음성 인식 원문에서 고쳐 쓰고, 확정 문장을 다듬을 때 지정한 번역을 참고합니다. 문장 다듬기가 꺼져 있으면 원문 고쳐 쓰기만 적용됩니다. 공개 기본 사전으로 원문이나 번역 결과를 일괄 치환하지 않습니다. 여러 개인 사전의 같은 오인식 표기가 서로 다른 용어를 가리키면 그 표기를 고치지 않습니다.

개인 파일은 `~/Library/Application Support/Live Korean Captions/Glossary/`에만 저장합니다. UTF-8 텍스트 파일을 사전당 256 KiB·300개 용어·개인 사전 32개까지 읽고, 각 번역에는 실제 등장한 용어를 최대 8개만 전달합니다. 자막을 시작할 때마다 다시 읽으며 번역 작업이 남아 있을 때는 다시 읽지 않습니다. 기존 `glossary.txt`의 내용은 그대로 유지합니다. 이전 일반 설정은 선택 없음, IT 설정은 AI, 내 용어집 설정은 AI와 기존 개인 사전으로 이행합니다. 모델이 용어를 항상 따르지는 않으므로 실제 발표 용어는 리허설로 확인하세요.

## 알아둘 제한사항

- 한 번에 한 화자와 한 번역 방향을 기준으로 합니다. 방향은 직접 바꿔야 하며, 언어 자동 판별과 여러 화자 구분은 지원하지 않습니다.
- 마이크 자동 선택은 시작 시 적용됩니다. 실행 중 입력을 바꾸려면 일시정지 후 다시 시작하세요.
- **컴퓨터에서 나는 소리**는 알림음을 포함해 이 Mac이 재생하는 모든 소리를 받습니다. 특정 앱만 고르는 기능은 없습니다. 재생 중인데 자막이 나오지 않으면 **시스템 설정 → 개인정보 보호 및 보안 → 화면 및 시스템 오디오 녹음**에서 이 앱을 허용했는지 확인하세요.
- 원본 음성을 녹음하거나 기록을 자동 저장하지 않습니다. 과거 전체 기록의 검색·불러오기 기능도 없습니다.
- 발음, 소음, 이름, 숫자, 부정 표현, 전문 용어에 따라 인식과 번역이 틀릴 수 있습니다. 필요한 경우 원문을 함께 확인하세요.
- 자막의 정확도와 지연은 기기와 입력 환경에 따라 달라집니다. 이 앱은 보조 자막 용도로 사용하세요.

## 개인정보와 외부 구성요소

앱은 번역용 외부 서비스에 음성이나 자막을 보내지 않습니다. 마이크와 컴퓨터 소리 모두 인식에만 쓰고 파일로 저장하지 않습니다. 초기 언어 자산과 선택 모델 다운로드에는 인터넷을 사용하며, 준비 후 추론은 로컬에서 실행합니다. 선택 모델은 파일 크기와 SHA-256을 확인한 뒤 설치하고, 모델 가중치는 저장소나 앱 번들에 포함하지 않습니다.

로컬 번역 런타임과 모델의 출처·라이선스는 [런타임 안내](Runtime/README.txt), [llama.cpp 라이선스](Runtime/llama-cpp-LICENSE.txt), [Hy-MT2 라이선스](Resources/ThirdParty/Hy-MT2-LICENSE.txt), [모델 고지](Resources/ThirdParty/Hy-MT2-NOTICE.txt)에 있습니다.
