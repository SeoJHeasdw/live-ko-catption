# 설정 팝업과 자막 화면 정리 — 2026-10-01

대상은 0.4.2 (10)입니다. 상시 사이드바를 제거하고, 상세 화면을 상단 도구막대·자막·하단 실행 영역으로 구성했습니다. 음성 인식·번역 스케줄러와 오디오 캡처는 변경하지 않았습니다.

## 화면 구성

- 상단 앱 도구막대는 54pt 높이의 한 줄입니다. 시작 전 번역 방향을 선택하고, 새 대화·저장·간략 보기·전체 화면·설정을 아이콘으로 조작합니다. 아이콘에는 동작을 설명하는 도움말과 접근성 이름을 제공합니다.
- 설정은 톱니바퀴가 여는 500pt 폭의 팝업에 있습니다. **자막**, **번역**, **마이크** 탭과 닫기 버튼을 제공하며 `Esc`로도 닫습니다. 탭을 바꿔도 자막 기록과 모델을 유지합니다.
- 원문 표시·글자 크기, 최근 구절 함께 번역·문장 다듬기, 마이크 수동 지정은 메인 화면에서 제거했습니다. 최초 언어 모델 준비와 진행 단계·진행률은 빈 자막 화면에 표시합니다.
- UI 본문은 15pt, 보조 문구는 14pt를 기준으로 합니다. 원문은 자막 크기에 맞춰 16~22pt로 표시하고 시간·상태는 13pt입니다. 원문 및 보조 글씨의 대비를 높였습니다.
- 한 대화의 번역 방향이 잠겨도 현재 방향은 읽기 쉬운 문구로 표시합니다. **원문 함께 보기**의 이름은 언어 중립이며 설명은 현재 입력 언어를 따릅니다.
- 간략 창의 상세 복귀는 확장 화살표 아이콘입니다. 상태와 조작 아이콘을 키우고 도움말에 동작·단축키·기록 유지 여부를 설명합니다.

## 마이크 자동 선택의 범위

자동 선택은 기존 캡처 동작을 사용합니다. 저장된 UID가 빈 값이면 매 시작 시 현재 시스템 기본 입력을 새로 읽습니다. 설정을 열거나 마이크 탭을 선택하면 장치 목록을 갱신하고, 시작 시에도 다시 확인합니다.

수동으로 지정한 마이크는 유지하며 연결되지 않으면 안내합니다. 실행 중 시스템 기본 장치 변경을 자동 추종하거나 연결 해제 후 자동 재시작하는 기능은 추가하지 않았습니다. 입력 변경은 일시정지 후 재개에 적용됩니다.

기존 사용자의 실행 앱과 대화는 유지했습니다. 0.4.1의 공개 예시 화면은 별도 보관하여 이전 검증 자료의 이미지가 바뀌지 않도록 했습니다.
