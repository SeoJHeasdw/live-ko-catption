# 실시간 번역 우선 처리와 간략 자막 읽기 — 2026-10-01

대상은 0.4.4 (12), UI 커밋 `297aa60`입니다. 빠른 영어에서 보정 작업 뒤로 새 초안이 밀리고, 좁은 간략 창의 내용이 크게 바뀌는 경로를 수정했습니다. Apple 음성 인식·빠른 번역, 오디오 콜백과 초안 번역 간격은 유지했습니다.

## 처리와 표시 변경

- 새 현재 초안도 선택 보완·문맥 작업을 선점합니다. 앞 구절의 정확한 Apple 기준 번역은 유지하고 늦은 선택 결과는 무시합니다. 이미 다음 초안이 대기 중이면 앞 구절의 보완을 시작하지 않습니다.
- 초안 번역 간격은 550ms입니다. 그 대기 중에도 새 최종 작업을 최대 50ms 간격으로 재확인합니다.
- 문맥 작업은 마지막 원문이 확정되고 새 원문 갱신 없이 750ms 지난 뒤 시작합니다. 뒤에 미확정 구절이 있으면 앞 문맥을 재시도하지 않습니다. 연속 발화에서는 상세 문맥 보정의 빈도가 낮아지는 절충이 있습니다.
- 간략 창은 개별 원문 구절의 번역을 표시합니다. 문맥 묶음은 상세 보기와 저장 기록에 유지합니다. 다음 번역을 기다릴 때 최근 읽을 수 있는 자막을 유지하고 새 대화에서는 비웁니다. 검색 범위는 최근 원문 100개, 표시 구절은 최대 2개입니다.
- 기본 간략 크기는 780×224, 최소 크기는 420×144입니다. 기존 저장한 크기는 유지합니다. 늘린 높이 전체를 자막에 사용하며, 완전한 줄에 맞춰 스크롤하고 한국어는 단어 경계를 우선합니다. 같은 앞 구절을 유지한 채 바뀐 뒤쪽만 교체합니다.

미확정 번역은 계속 회색으로 바뀔 수 있습니다. ASR의 잦은 수정 자체를 멈추거나 오래된 원문 번역을 현재의 확정 결과로 표시하지 않습니다.

새 모델 검사는 멈춘 보완·문맥 작업에 현재 초안이 우선권을 얻는지, 대기 초안이 있으면 보완을 건너뛰는지, 최종 작업이 초안 대기에서 빠져나오는지 확인합니다. 문맥 정숙 대기·재시도 방지·늦은 결과 거부와 번역 대기 중 이전 자막 유지·새 대화 초기화·회색 상태·오류 노출도 확인합니다. 주입한 번역기와 취소를 무시하는 시험 작업을 사용하며 실제 모델 속도를 측정한 검사가 아닙니다.

초기 화면 검사는 마지막 글자 표시와 높이 확장만 확인해 통과했지만, 직접 예시 화면에서 맨 윗줄이 반쯤 잘리는 문제가 보였습니다. [줄 정렬 전 자료](raw/compact-reading-before-line-alignment-20261001.jsonl)는 이 검사 누락을 기록합니다. 완전한 첫 줄 위치로 맞추고 아래 여백을 네이티브 문서 안에 추가했습니다. 이어서 위·아래가 온전히 보이는 조건을 통과 기준에 넣었습니다.

최종 144·224·320pt 높이에서 실제 자막 영역은 각각 72·152·248pt였으며, 위쪽 줄과 마지막 글자가 모두 온전히 표시됐습니다. 줄 정렬 화면은 별도 예시 앱에서 직접 확인했습니다. 최종 한국어 단어 경계·초기 0 크기 가드는 네이티브 자동 검사 범위입니다. `hangulWordPriority`의 macOS 11.0 가용성을 SDK 헤더에서 확인했습니다.
