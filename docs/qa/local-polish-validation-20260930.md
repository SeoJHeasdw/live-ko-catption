# 로컬 문맥 다듬기 검증 — 2026-09-30

Hy-MT2-1.8B Q6_K는 이 Mac의 합성 텍스트 검사에서 빠르게 번역했지만, **문맥을 합친 경우에도 뜻을 바꾸는 결과가 있었다. 형식·숫자 검사를 통과하는 것만으로 정확한 자막이라고 판단할 수 없다.** 선택 기능의 기본값을 꺼 두고, 필요할 때 사용자가 켜는 실험 기능으로 유지하는 것을 권고한다.

실시간 마이크·음성 인식·앱 전체의 자막 지연을 측정한 보고서는 아니다. 모든 원문은 직접 작성한 공개 가능한 합성 예문이다. 개인정보가 담긴 실제 발화는 사용하지 않았다.

다음 수치는 모델 내부 번역 시간이며 마이크 입력부터 자막 표시까지의 시간과 다르다. 소수 예문의 p95는 일반적인 성능 보장이 아니다.

|---|---:|---:|---:|
| 최초 v1 source-only | 24 | 39.211 / 69.084 ms | 175.517 / 306.027 / 425.303 ms |
| 현재 v2 source-only | 24 | 29.285 / 64.067 ms | 171.680 / 358.478 / 551.176 ms |

모델 초기 로드는 각각 v1 14,454.932 ms, v2 15,372.829 ms, 문장 묶음 검사 16,891.854 ms였다. 시작 전에 모델을 준비하는 비용으로 다뤄야 하며, 반복 번역 시간에 합쳐서 설명하지 않는다.

30분 실행은 2026-09-30 **18:27 KST 이후 시작해 1,800.564초 동안 865회** native 번역을 수행했다. 목표 시작 간격은 2초였고, 느린 실행 후 놓친 시점을 따라잡는 작업은 생성하지 않았다. 한 번에 native 요청 하나만 실행했다. 865회 모두 완료했고 시간 초과는 없었다. 원시 후보 829회가 당시의 형식·숫자 검사를 통과했으며, 이는 의미 정확도 평가가 아니다.

- 현재 RSS: 시작 1,768,177,664 bytes → 종료 1,717,944,320 bytes.
- 실행 중 샘플 RSS 범위: 1,717,895,168–1,769,521,152 bytes.
- 프로세스 lifetime peak RSS: 종료 시 1,769,553,920 bytes. peak는 단조 증가하는 최고 기록이며 현재 메모리와 구분한다.
- 샘플의 OS 온도 상태는 모두 `nominal`이었다. 팬 소음은 측정하지 않았다.
- 사용자는 검사 중 자리에 계속 앉아 다른 작업을 병행했고, 팬 소음이 나지 않았다고 직접 확인했다. 이 환경의 실제 사용 관찰이며 팬 회전수 계측이나 다른 Mac에서의 소음 보장은 아니다.
- 같은 프로세스의 실제 busy 거부, 실행 중 취소, 취소 뒤 재사용, 완료된 과거 task의 늦은 취소가 다음 요청에 영향을 주지 않는 검사를 통과했다. v1 취소 반환은 18.731 ms였다.

**실행 실패도 기록한다.** 검사기는 `Soak complete`를 출력하고 865개 샘플을 포함한 최종 JSON을 저장했지만, 이를 실행한 shell wrapper는 그 후 `permission denied: Sources/LiveKoCaption/LocalTranslationEngine.swift`로 exit 126을 냈다. 실행 중 같은 스크립트에 build 경로 설명/설정을 추가하면서 zsh가 변경된 파일 위치를 다시 읽은 것이 원인으로 보인다. 이 설명은 추론이다. 저장된 native 검사 결과와 wrapper 실패를 구분하며, wrapper 전체가 성공했다고 보고하지 않는다. 후속 launcher는 마지막 명령에 `exec`를 사용하게 수정했다. 문장 묶음 후속 실행은 exit 0으로 완료했다.

당시 전체 작업 소스를 시작 시점에 보관하지는 않았다. 최초 실행의 컴파일된 checker/CaptionCore 해시와, 실행 전에 읽은 v1 프롬프트 구조를 메타데이터에 기록했다. 현재 코드에 대한 30분 검증으로 바꾸어 주장하지 않는다. 개발 작업과 별도 후속 검사가 같은 Mac에서 진행됐으므로 컴퓨터 전체가 이 검사만 실행한 환경이라고 주장하지 않는다.

## 별도 background 실험의 한계

앱에서 사용하지 않는 `previousSentence` 실험은 별도로 남겼다. v1에서는 이전 문장을 출력에 복사하거나 `원문:`/`Source text:` 라벨을 붙이고, 피구를 야구로 바꾸는 문제가 있었다. v2는 프롬프트를 단순화하고 background를 앞에 배치했지만 문제가 모두 사라지지 않았다.

- 영어 rollback에서는 실제 source 대신 배경/용어 지시를 번역했고, 형식 가드가 거부했다.
- 한국어 Kubernetes에서도 실제 source 대신 배경 문장만 출력했고, 형식 가드가 거부했다.
- 한국어 bank에서는 `계좌를 개설하려고 지점에 들를 것`이라는 배경만 출력했지만 가드는 통과했다.
- 한국어 precision/recall에서는 재현율 분모를 다시 탐지 항목으로 바꿨지만 가드는 통과했다.
- 영어 `piece of cake`를 `몇 번만 하면 됩니다`로 바꿔 쉬운 작업이라는 관용 의미를 훼손했지만 가드는 통과했다.

따라서 `guardAccepted`는 형식과 숫자의 명백한 손상을 줄이는 장치로 설명해야 한다. 의미 보존·전문 정의·조건·종목·요청과 완료 사실의 구분을 보증하는 검사가 아니다.

## 모델 설치 상태 회귀검사

`./scripts/check-local-model-store.sh`가 Swift 6 엄격 동시성, arm64 macOS 26.4 대상으로 컴파일되고 exit 0으로 완료했다. 실제 모델 다운로드나 네트워크 성공을 가정하지 않는 작은 파일 검사다.

- 파일 누락 시 준비 상태와 modelURL이 활성화되지 않음.
- 기대 SHA-256을 가진 파일만 준비 상태로 전환됨.
- 변경되지 않은 정상 파일의 재확인 결과 유지.
- 크기가 같아도 내용이 바뀐 파일은 준비 상태에서 제외됨.
- 크기가 다른 파일은 제외됨.
- 명시적 다운로드 요청 직후 취소하면 다운로드/검증 상태와 partial 파일이 남지 않음.
- 32 MiB 공개 합성 파일을 스트리밍 검증하는 동안 두 `refresh()` 호출을 겹치면, **두 호출 모두 검증이 끝난 준비 상태와 같은 modelURL을 보고 반환함**. 검증 중인 두 번째 호출이 modelURL=nil인 상태로 먼저 반환하던 문제를 대상으로 한다.

테스트 파일은 종료 시 삭제한다. 이 검사는 다운로드 서버의 전송 성공, UI 조작, 실제 모델 번역의 정확도를 검증하지 않는다.

## 앱 상태와 화면 확인

양방향 일반/IT 네 개의 실제 파일 음성 인식→Apple 초안→HY 보완 연결은 모두 통과했다. [파일 통합 검사 조건과 의미 오류](bidirectional-polish-file-pipeline.txt), [공개 원자료](raw/bidirectional-polish-pipeline-20260930.json)를 따른다. 한국어 IT의 인식 오류와 영어 rollback 의역 차이는 별도로 남아 있다.

최종 코드의 CaptionCore 26개, 앱 모델 33개, 번역 큐 7개, deadline 3개, TranslationSessionLease 5개 검사를 통과했다. 앱 모델 검사에는 저장된 보완 ON 설정·toggle 직후에도 예열 전에 Start가 열리지 않는 상태, 준비 실패 시 OFF/빠른 번역 복구, ASR-final과 exact revision 확인, 늦은 결과 차단, 다음 final 우선, 중단 시 정확한 빠른 결과 보존, native context timeout 후 추가 문맥 중단이 포함된다. 결정적 검사에는 실제 마이크나 GPU를 사용하지 않았다.

실제 네이티브 ABI의 동시 요청 거부·실행 중 취소·오래된 요청 ID 취소 무시·시간 초과·토큰 제한·UTF-8 버퍼 잘림·컨텍스트 초과·복구 8개도 통과했다. [공개 검사 원자료](raw/local-runtime-abi-20260930.jsonl)는 `Tests/LocalRuntimeChecks/check.py`로 재현할 수 있다. 아래 경로는 이미 준비된 모델과 런타임을 읽으며 다운로드하지 않는다.

```sh
python3 Tests/LocalRuntimeChecks/check.py \
  --model /absolute/path/to/Hy-MT2-1.8B-Q6_K.gguf \
  --runtime .build/local-runtime/libcaption_local_translation.dylib
```

0.4.0 실제 앱에서 설치된 모델 확인, checkbox ON, 시작 전 로딩/예열 동안 Start 비활성화, 준비 후 활성화, 일반/IT 및 양방향 라벨 전환을 직접 확인했다. 이후 IT 보완을 켜 실제 내장 마이크로 시작했고, 자막과 문맥 묶음이 생성된 뒤 1분 54초 기록을 보존한 정지 상태를 확인했다. 이 실제 발화는 사용자의 자료이므로 원문·번역을 공개 보고서에 복사하지 않았다. 정확성이나 전체 지연의 통제된 측정으로 취급하지 않는다. 현재 사용자의 열린 대화는 보존한다.

별도 시험 앱의 [66.47초 합성 표시 결과](raw/ui-local-polish-controls-final-20260930.jsonl)는 PASS다. 보기 전환 15회, 간략 표시 최대 두 구절, 최소 크기, 테두리 입력 2회, 최신 마지막 글자 표시, 모델/기록/실행 상태 유지와 전체 31개 구절 보존을 확인했다. 문장 다듬기는 이 합성 UI 검사에서 꺼져 있으므로 HY의 GPU/마이크 장시간 검증을 대신하지 않는다.

첫 UI 검사 실행은 상대 보고서 경로를 넘겨 시험 앱의 작업 디렉터리에서 파일을 찾지 못했다. `check-ui-soak.sh`에서 보고서 경로를 절대 경로로 정규화한 뒤 재실행은 exit 0으로 완료했다. 첫 실패를 자막 상태 검사 통과로 집계하지 않는다.
