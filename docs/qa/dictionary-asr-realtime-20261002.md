- 한국어 → 영어 다듬기는 두 조건 모두 원문에 없는 `last week`를 추가했습니다. 숫자·형식 검사 통과는 이런 의미 추가를 검출하지 못했습니다.
- 영어의 `I cannot recall the last planning meeting.`은 사전 없음에서 마지막 계획 회의를 기억하지 못한다는 뜻으로 옮겼지만, 세 사전 조건의 문장별 다듬기는 회의가 **언제였는지** 기억하지 못한다는 뜻으로 좁혔습니다. `recall`을 분류 지표인 재현율로 바꾸지는 않았으나 의미 보존에 실패한 부분이 남았습니다.
