# UI·UX 개선 검증 — 2026-10-01

대상은 0.4.1 (9)입니다. 상세 화면의 설정 우선순위, 실행·저장 동선, 상태 안내와 간략 창의 접근성을 다듬었습니다. 음성 인식·번역 스케줄러와 오디오 처리는 변경하지 않았습니다.

## 변경 내용

- 상세 화면은 번역 방향과 마이크를 먼저 보여줍니다. 추가 옵션은 **번역 설정**, **자막 표시**로 나눠 접을 수 있습니다.
- **자막 시작·일시정지·자막 재개**, **기록 저장**, **새 대화**는 설정 스크롤과 분리된 하단 영역에 유지합니다. 비활성 창에서도 사용 가능한 시작 버튼의 대비를 유지합니다.
- 자막이 없는 화면은 언어 확인·다운로드·로컬 모델 준비·마이크 연결·듣기·마지막 정리 상태에 맞춰 안내합니다.
- 보기와 대화 조작의 명칭을 통일하고, 새 대화 확인 창은 저장 여부에 따른 결과를 명시합니다.
- 간략 창은 키 창이거나 VoiceOver가 활성화된 경우에도 조작 버튼을 표시합니다. 단축키 도움말과 오류·상태 접근성 설명을 추가했습니다.
- 상세 화면의 글자 크기와 자동 따라가기에는 접근성 이름·값을 제공합니다. 개별 처리 시간은 실제 값이 있을 때 열 수 있는 팝오버에 모았습니다.

## 빌드와 상태 검사

| 검사 | 결과 | 범위 |
|---|---|---|
| `./scripts/build-app.sh` | 통과 | macOS 26.4 대상 릴리스 앱과 포함 런타임 구성 |
| `./scripts/check-app-model.sh` | 33개 통과 | 기존 모델의 수정 버전·보완·취소·확정·재시도·정리 동작 |
| `./scripts/check-ui-soak.sh 65 /tmp/caption-ux-final-20261001.jsonl --ui-soak-compact` | 통과 | 별도 시험 앱의 합성 표시·보기 전환·창 크기·기록 유지 |

앱 모델 검사는 UI 클래스 자체를 검증하지 않습니다. UI의 최종 변경 후 릴리스 빌드와 합성 화면 검사를 수행했고, 변경하지 않은 모델의 검사는 별도로 실행했습니다. 추가한 SwiftUI 환경·포커스·접기·팝오버 API는 설치된 SDK의 선언에서 최소 지원 버전을 확인했으며 macOS 26.4보다 새로운 API를 요구하지 않습니다.

## 직접 화면 확인

별도 번들 ID의 시험 앱을 사용했습니다. 기존 실행 중인 앱과 대화를 종료하지 않았고 시험 앱의 마이크를 시작하거나 모델 다운로드를 요청하지 않았습니다.

- 상세 화면의 최소 콘텐츠 크기 950×660에서 기본 설정과 고정 실행·기록 영역을 확인했습니다. 설정 두 그룹을 펼치고 스크롤해도 실행·저장·새 대화 영역이 남았습니다.
- 빈 대화에서 양방향 선택, 대상 언어 제목과 시작 안내, 준비된 시작 버튼, 빈 기록 저장의 비활성 상태를 확인했습니다.
- 예시 대화에서 번역·표시 설정과 슬라이더의 접근성 이름·포인트 값을 확인했습니다.
- 새 대화 확인 창의 저장·저장하지 않기·취소 선택을 확인하고 취소했습니다.
- `⌘2`로 간략 보기, `⌘1`로 상세 보기에 복귀하면서 예시 원문·번역과 설정이 유지됨을 확인했습니다.
- [공개 미리보기](../images/archive/caption-preview-0.4.1.png)는 앱이 생성한 예시 대화입니다. 실제 사용자 발화나 측정 성능을 포함하지 않습니다.

## 검증 범위

이번 작업은 UI 구성과 화면 안정성 검사입니다. 실마이크 정확도, 실제 자막의 전체 지연, 번역 의미, 장시간 발열·팬 소음과 오프라인 실행은 새로 측정하지 않았습니다. VoiceOver의 실제 음성 탐색과 준비·번역 실패의 모든 화면을 직접 조작해 확인하지는 않았습니다. 접근성은 코드 검토와 macOS 접근성 트리에서 확인한 범위로 해석합니다.
