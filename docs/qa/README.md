# 검증 자료 안내

이 폴더는 기능별 검사 조건, 실패 사례와 원자료를 보관합니다. 일반 사용 방법은 [프로젝트 README](../../README.md), 검사 실행 방법은 [개발 가이드](../development.md)에 있습니다.

검사 통과는 해당 자료에 명시된 상태·실행 경로가 동작했다는 뜻입니다. 마이크 연결, 화면 안정성, 음성 인식 정확도, 번역 의미와 지연은 각각 범위가 다릅니다. 합성 파일이나 합성 화면의 결과를 실제 화자의 전체 사용 성능으로 해석하지 않습니다.

## 해석 시 주의사항

- **상태 검사**는 최신 원문 버전과 번역의 일치, 회색→최종 조건, 취소·종료를 확인합니다. 번역 의미를 판정하지 않습니다.
- **파일 음성 검사**는 준비된 합성 파일과 언어 자산을 사용합니다. 마이크 하드웨어·실제 발음·환경 소음을 포함하지 않습니다.
- **화면 검사**는 별도 시험 앱의 합성 상태를 표시합니다. 실제 음성 인식이나 번역 속도를 측정하지 않습니다.
- **네이티브 모델 검사**의 첫 토큰·전체 생성 시간은 앱 전체 자막 지연과 다릅니다. 모델 초기 로딩 비용과 반복 생성 비용도 구분합니다.
- **마이크 입력 검사**의 연결·재시작 성공은 기준 대본과 비교한 정확도 평가가 아닙니다.
- **형식·숫자 가드**는 번역의 의미 오류를 모두 발견하지 못합니다. 선택 모델이 Apple 번역보다 항상 낫다는 근거로 사용하지 않습니다.

보고서에는 초기 실패, 취소되지 않은 SDK 요청, 검사 도구의 오류와 대상 버전 차이도 보존합니다. 통과한 후속 결과가 과거 실패 자료를 대체하거나 지우지는 않습니다.
