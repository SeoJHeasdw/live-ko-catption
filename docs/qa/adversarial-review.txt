2026-09-30 실 사용 기준 적대적 리뷰 결과

판정: 쉬운 영어 발화를 따라가는 보조 자막으로 조건부 사용 가능하다. 자연스러운
통역이나 의미가 검증된 기록을 대신할 수준은 아니다. 구조적 결함은 수정했지만,
Apple 번역 엔진 자체의 중의어·전문 용어·수치 관계 오역은 남아 있다.

수정한 주요 결함

P1 · 스테레오 오른쪽 음성 소실
일부 USB/핀마이크 수신기의 오른쪽 채널만 들어오는 음성이 기존 모노 변환에서
사라졌다. downmix를 명시하고 출력 샘플·입력 레벨을 함께 검사한다.

P1 · 시작 취소 뒤 녹음 재실행과 이전 작업 혼입
권한/모델 준비를 기다리던 시작 작업이 정지 후 계속 진행할 수 있었다. 실행과
번역 작업에 각각 식별자를 부여하고 모든 대기 뒤 확인한다. 이전 대화의 늦은
번역·오류는 새 대화에 반영하지 않는다. 시작 중에도 취소할 수 있다.

P1 · 확정 원문이 초안·문맥 작업 뒤에 대기
큐의 순서만 바꾸면 이미 진행 중인 시스템 작업은 새 확정 결과를 계속 막았다.
독립적인 취소/시간 제한을 적용해 오래 걸리는 초안·문맥을 선점한다. 동일한
원문이 그대로 확정되면 이미 진행 중인 번역을 재사용한다. 예상하지 못한 번역
서비스 취소도 실패 표시와 재시도가 남는다.

P1 · 이전 자막을 문맥으로 다시 볼 경로가 없음
최근 2~4개 확정 구절을 12초·500자 안에서 함께 번역한다. 확인 중 회색으로
표시하고 완료 후 문맥 묶음으로 바꾼다. 모든 원문 버전과 문맥 버전이 정확히
일치할 때만 반영한다. 원래 ASR 기록은 변경하지 않으며 과거 전체를 재번역하지
않는다. 실제 시험에서 세 번째 구절의 화요일 발언과 네 번째 구절의 목요일 정정이
갈라지는 경계를 발견해 네 구절까지 확장했다. 한도 밖의 옛 문맥까지 고치지는 않는다.

P2 · 정지 직전 입력과 변환기 끝부분 누락
이미 접수했으나 복사 중인 버퍼보다 스트림 종료가 먼저 실행될 수 있었다. 접수한
입력을 모두 변환하고 변환기의 마지막 출력을 비운 후 종료한다. 48k→16k 검증의
출력은 기존 1,360프레임에서 필요한 1,600프레임으로 복구됐다.

P2 · 입력 지연 누적과 듣는 상태에서 무응답
변환 대기는 입력 0.5초, 분석 스트림은 8개 버퍼로 제한한다. 누락 횟수를 기록하며
오류 알림은 한 번만 전달한다. 실제 입력 뒤 엔진이 멈추면 공백을 숨긴 채 재시작하지
않고 정지한다. 첫 버퍼가 없거나 입력이 3초 넘게 끊겨도 정지한다. 무음 버퍼는
정상 입력이다. 선택했던 마이크가 없으면 기본 마이크로 몰래 전환하지 않는다.

P2 · 정리/번역 대기와 실패 복구
번역 응답 6초, 문맥 보정 4초, 정지 정리 전체 8초의 회복 한도를 둔다. 입력이
번역보다 계속 빠르면 입력을 멈추며 미완료 원문을 보존한다. 실패마다 원문과 재시도
버튼을 남기고, 배너를 닫아도 복구 경로는 남는다. 성공한 재시도는 번역 실패 표시를
지운다. 저장 기록에는 미확정 상태와 입력 누락 가능성의 알림을 남긴다.

실제 엔진 검사

20개 영어 입력 × 두 번역 전략의 실제 결과 40개를 비교했다. 모든 전략 쌍의 출력이
같았다. 이어지는 not only … but also를 함께 번역하면 부정 해석이 바뀌었다.
그러나 몸을 숙이는 duck은 오리로 남고, 실제 케이크는 식은 죽 먹기로 남았다.
below 0.05는 0.05 이하가 됐고, 원문에 없는 오후를 추가했으며 Dr. Lee와 전문
용어의 연결도 실패했다. 이런 출력을 코드의 단어 치환으로 고치면 새 오역을 만들 수
있어 자동 치환하지 않았다. 상세 판정은 translation-quality-review.txt에 있다.

15.627초 합성 영어를 실제 속도로 보내 로컬 ASR → 실제 앱 상태/큐 → 로컬 한국어
번역을 함께 실행했다. 중간 인식 64회, 확정 구절 6개를 모두 보존했다. 첫 정확한
회색 한국어는 입력 시작 1.698초 후 관찰됐고 해당 음성 구간 끝으로부터 0.599초였다.
최신 원문과 일치하는 번역의 관찰 지연 18개는 중앙값 0.597초, 최대 1.140초였으며
대기는 최대 2개, 입력 누락 0개였다. 진한 자막에서 회색으로 돌아가는 전환 4회와
실제 문맥 번역 4회도 확인했다. 종료 후 미완료 작업은 없었다.

이는 준비된 엔진·단일 합성 파일·20ms 간격의 화면 모델 관찰이다. 마이크 하드웨어와
SwiftUI 그리기 시간은 포함하지 않는다. 검사 번역기는 호출별 세션을 만들며 앱은
빠른 번역 세션을 재사용한다. 실시간 마이크의 지연이나 장시간 안정도를 입증하지
않는다. 실제 원자료와 제한은 2026-09-30-realtime-pipeline.json에 있다.

의미 보정의 한계

이번 실제 파일에서 화요일→목요일 문맥은 한 묶음에 포함됐지만, 엔진은 이전 절을
지우거나 다시 해석하지 않고 이전 생각과 정정을 함께 번역했다. 문맥 재번역 경로와
색 전환은 확인됐으며, 모든 완성 문장의 오역을 자동으로 고친다고 주장할 수 없다.
화면의 진한 색은 확정 원문과 번역 버전의 일치만 뜻한다.

추가 실 사용 항목과 남은 확인

- 실제 화자의 억양·빠르기·작은 목소리·소음·영어/한국어 혼합과 다른 사람의 목소리:
  화자 분리나 의미 검증을 제공하지 않는다. 영어 화자 가까이의 마이크가 필요하다.
- 이름·요일·날짜·금액·소수·퍼센트·단위·부정·조건·전문 용어: 원문 대조가 필요하다.
  용어집/스타일 지시 기능과 다른 로컬 모델 비교는 아직 제공하지 않는다.
- 긴 문맥·대명사·미완성 문장·뒤늦은 정정: 최근 한도 안에서만 문맥을 제공한다.
  충분한 문맥을 줘도 오역이 남을 수 있으며 오래된 확정 묶음은 고정된다.
- 20~30분 이상 연속 입력, 실제 핀마이크 지연, 뽑기/재연결, Mac 잠자기/깨우기와
  권한 변경: 코드 경로와 모의 검사는 통과했으나 실제 하드웨어 반복 검증이 남았다.
- 완전 오프라인: 설치된 언어 세션만 사용하고 외부 번역 서비스를 추가하지 않았다.
  네트워크를 끈 실제 사용은 이번 검증에 포함하지 않았다.
- 기록 보존: 자동 저장/원본 녹음은 하지 않는다. 필요한 기록은 사용자가 저장해야
  하며 앱 종료 후 미저장 기록 복원은 제공하지 않는다.
- 가독성/조작: 회색 초안, 이전 번역 갱신, 문맥 확인, 실패 상태를 구분한다. 최신
  따라가기는 다시 켜는 즉시 이동하며 큰 글씨·자막만 보기·전체 화면을 유지한다.
