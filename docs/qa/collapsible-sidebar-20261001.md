# 왼쪽 접이식 사이드바 — 2026-10-01

대상은 0.4.3 (11), UI 커밋 `6d1e0a2`입니다. 상세 화면의 조작을 왼쪽 사이드바로 옮겼습니다. 음성 인식·번역 스케줄러와 오디오 캡처는 변경하지 않았습니다.

## 화면과 설정

- 펼친 사이드바는 260pt, 접힌 아이콘 열은 56pt입니다. 간략 보기·전체 화면·기록 저장·새 대화·설정은 양쪽 상태에서 사용할 수 있습니다.
- 상단 왼쪽 버튼 또는 `⌘\`로 접고 펼칩니다. 폭과 라벨은 0.22초 동안 전환하며 시스템의 동작 줄이기를 따릅니다. 접힘 상태는 다음 실행에도 유지됩니다.
- 빠른 설정은 일반·IT 번역 분야만 표시합니다. 선택 모델의 문장 다듬기에만 적용되고 Apple의 빠른 번역에는 적용되지 않습니다. 문장 다듬기를 꺼 둔 빈 대화에서도 미리 선택할 수 있으며, 기록이 있으면 현재 분야를 표시하고 변경을 막습니다.
- 나머지 설정은 톱니바퀴의 자막·번역·마이크 탭에 있습니다. 빠른 설정의 문장 다듬기 링크는 번역 탭을 바로 엽니다.
- 헤더는 기존 54pt 높이를 유지합니다. 기본 상세 크기는 1180×760, 최소 콘텐츠 크기는 860×560입니다. 시작·일시정지·재개는 하단에 있습니다.

[펼친 예시 화면](../images/caption-preview.png)과 [접힌 예시 화면](../images/caption-sidebar-collapsed.png)은 합성 대화입니다. 사용자 기록이나 성능 수치를 포함하지 않습니다. 이전 0.4.2 화면은 [별도 보관](../images/archive/caption-preview-0.4.2.png)했습니다.

## 실패 재현과 수정

폭 변경 전에는 자막 뷰를 다시 만들지 않아도 TextKit의 줄바꿈으로 읽기 위치가 밀렸습니다. [폭 보정 전 실행](raw/collapsible-sidebar-before-width-fix-20261001.jsonl)은 최신 따라가기 상태를 먼저 확인했지만, 펼친 폭에서 마지막 글자가 화면 밖으로 벗어났고 접힌 폭에서 과거 구절의 위치가 바뀌어 실패했습니다. 텍스트 선택은 유지됐습니다.

네이티브 텍스트 뷰가 새 폭을 받기 전에 구절 ID·문자 위치·세로 오프셋을 잡고, 폭 갱신을 60ms 단위로 묶어 줄 배치를 완료한 뒤 위치를 복원합니다. 최신 따라가기에서는 마지막 부분을 표시합니다. 이 처리는 네이티브 뷰 안에서 수행하며 문서 높이를 SwiftUI 창 크기로 전달하지 않습니다. 사용자의 스크롤이나 탐색은 예약된 복원보다 우선하고 따라가기를 중단합니다.

설정 링크의 초기 탭도 직접 확인했습니다. 별도의 팝업 표시 여부와 탭 상태를 사용하면 첫 열기에서 자막 탭이 나타나는 문제가 있어, 선택한 탭 자체를 팝업 항목으로 전달하도록 바꿨습니다.

직접 조작은 별도 번들 ID의 시험 앱에서 수행했습니다. 최소 상세 크기의 펼침·접힘, 아이콘과 하단 버튼, 단축키, 양쪽 상태의 설정 열기를 확인했습니다. 문장 다듬기가 꺼진 빈 대화에서 IT 선택을 확인했고, 접은 뒤 종료·재실행하여 접힘 상태가 유지됨을 확인했습니다. 예시 기록이 있는 화면에서 분야 잠금과 번역 설정 직행도 확인했습니다.

동작 줄이기는 코드 경로를 확인했으며 시스템 설정을 변경해 직접 재측정하지 않았습니다. VoiceOver 실제 음성 탐색, 실제 마이크 입력, 인식·번역 정확도, 전체 지연과 장시간 열·팬 소음은 이번 화면 검사 범위에 포함하지 않습니다. 기존 사용자의 실행 앱과 대화는 유지했습니다.
