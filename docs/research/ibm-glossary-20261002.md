# IBM 공개 용어사전 조사 — 2026-10-02

IBM 공식 한국어 제품 페이지에서 확인한 공개 제품명 20개를 후보로 정리했습니다. 한국어 페이지에서도 영문 제품명을 사용하므로 이 후보는 번역어를 새로 만들지 않고 영문 표기를 유지합니다. 등록상표 기호는 자막에 넣지 않습니다. 아래 설명은 제품 구분을 위한 짧은 요약이며 IBM 원문의 인용이 아닙니다.

## 적용 범위

- IBM 내부 약어, 직원명, 고객명, 프로젝트명, 비공개 제품·계약 정보는 포함하지 않습니다.
- 음성 인식 오인식 별칭과 자동 원문 치환 규칙은 포함하지 않습니다. 사용자가 직접 적은 표기만 개인 사전에서 처리합니다.
- `Granite`, `Power`, `Concert`처럼 일반어로도 쓰이는 이름은 `IBM`을 포함한 표기만 후보로 사용합니다. `MQ`와 `Z`도 단독으로 등록하지 않습니다.
- 제품 이름의 `IBM` 접두어가 없는 후보는 공식 이름의 구별 가능한 본체입니다. 번역 시 원문에 없는 `IBM` 접두어를 추가하지 않습니다.
- 제품 버전, 가격, 성능 주장, 출시 상태는 기본 용어사전에 넣지 않습니다. 용어 참고는 의미·음성 인식 정확도 보장이 아닙니다.

## 확인 중 발견한 점

- `https://www.ibm.com/kr-ko/products/watsonx-code-assistant`는 확인 시 `https://www.ibm.com/kr-ko/products/ai-coding-agent`로 이동했습니다. 따라서 일반 이름의 현재 대표 페이지를 근거로 고정하지 않고, 독립 공식 페이지가 확인된 `watsonx Code Assistant for Z`를 후보로 사용했습니다.
